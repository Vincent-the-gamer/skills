# skills

Vincent's Agent Skills

> [!TIP]
> Hint: `disable-model-invocation: true` means that the user need to trigger the skill manually, the agents won't trigger it automatically.

## Installation

```bash
npx skills@latest add Vincent-the-gamer/skills
```
