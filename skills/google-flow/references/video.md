# 付费视频分支

**只有在用户明确说“生成视频 / 用 Veo / 做成视频 / 让这张图动起来”，并且你已告知会消耗积分、用户确认后，才使用这份文件。** 图片生成是免费的；视频不是。

## 进入前

- 先说清楚：图片免费，视频按积分计费；费用以 Generate 按钮上的显示为准。
- 问用户本次最多点几次 Generate；确认后再操作。
- 优先从用户已经接受的图片开始：把那张图作为首帧或 ingredients，而不是重新描述一遍。

## 模式

| 用户给了什么 | 模式 |
| --- | --- |
| 首帧 / 尾帧图 | Frames to Video |
| 角色、物体、场景参考图（通常最多三张） | Ingredients to Video |
| 只有文字 | Text to Video |

选视频模式、Veo 模型（Fast / Quality）、画幅和条数；这些入口通常在图片/素材的生成菜单里，不在右侧免费 Agent 面板的默认流程里。**只走用户确认过的那条入口。**

## 流程

1. 从项目里的图片或素材进入视频模式；或按页面入口新上传参考图。
2. 选 Veo 模型、画幅、条数，读清积分消耗。
3. 写视频提示词（见下）。
4. 点 Generate 一次；等 1–3 分钟，Quality 更久；每 30–60 秒 `observe` 一次。
5. 验收：动作、人物一致性、手部、文字、音频/口型。
6. 下载按页面流程；目标文件已存在时先问。
7. 结束后 `bsk session stop <sid>`。

付费动作只点一次；结果未知时先观察、对账，再决定是否重试。

多镜头连续性、`@` 句柄、自包含提示词和文字政策，按 [prompt-optimizer.md](prompt-optimizer.md) 的原则。上游仓库的 `scripts/validate.py` 可用于视频/分镜包；图片流程不依赖它。

## 视频提示词

```text
主体 + 动作 + 场景 + 镜头/运动 + 光线/风格 + 声音
```

- 第一行先写文字政策：`NO TEXT IN THE IMAGE...` 或 `INTENTIONAL TEXT IN THE IMAGE...`。

- 一条只做一个主要动作；单条通常 8 秒。
- 镜头运动只写一个：`static wide shot`、`slow dolly in`、`handheld tracking`、`pan left`。
- 对白只写一句，标明说话人和语言；环境音、音效单独点名。
- 参考图必须点名职责。

下面的模板省略了文字政策；复制时在开头补一行 `NO TEXT IN THE IMAGE...` 或 `INTENTIONAL TEXT IN THE IMAGE...`。模板里的 `图 1/2/3` 在实际使用时换成 `@` 句柄。

### 首尾帧

```text
以参考图为首帧。女人从门口走向柜台，把伞放在台面上，抬眼看向镜头。
镜头跟随她缓慢横移，保持室内暖光和胶片颗粒。环境音：雨声、脚步、伞面滴水。
```

有尾帧时补一句终点状态：“最后一帧停在柜台前的近景，构图与尾帧一致。”

### 素材合成

```text
图 1 的女人，拿着图 2 的白色陶瓷杯，站在图 3 的雨夜街角。
中景，缓慢推近，她低头喝了一口，抬眼看向镜头。
霓虹反光，冷色调，浅景深。环境音：雨声、远处人声。
```

### 文生视频

```text
中景，一位穿灰色风衣的女人在雨夜推开旧书店的玻璃门，门铃轻响。她收起伞，抬头看向书架。
镜头缓慢推近。暖色钨丝灯，35mm 胶片颗粒，浅景深。
环境音：雨声、门铃、远处车辆。
```

## 费用与失败

| 现象 | 处理 |
| --- | --- |
| 积分不足 / 订阅墙 | 停；告诉用户页面要求；购买由用户决定 |
| 生成被政策拒绝 | 引用页面提示，给两个改写方案，问用户选哪个 |
| 超过 10 分钟没动静 | 只点过一次就继续等或问用户；截图报告状态 |
| 结果不像参考图 | 换更干净的参考图，或减少运动/人数 |
| 用户改主意不做视频 | 回项目页右侧 Agent 面板继续图片流程；已付费的结果保留，不重复生成 |

## 回到图片

用户只是想看图或改图时，回到项目页右侧 Agent 面板；图片生成免费，不需要走视频入口。
