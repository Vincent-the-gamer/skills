# ncmdump

> [!NOTE]
> I recommend you to install/download ncmdump first.
>
> For Rust developers: `cargo install ncmdump-bin`
>
> For Users: [ncmdump.rs releases](https://github.com/iqiziqi/ncmdump.rs/releases), and add it to PATH.

`.ncm` is a format of netease cloud music copyright protection file.
This skill is to dump the original audio file using ncmdump.rs

## Trigger Words

```
I'll give you a .ncm audio file next, please call ncmdump skill to decode it to .mp3 for me, and send me the file.
```
