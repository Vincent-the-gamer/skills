# 轨言轨语（kiseki-lang）

把任何一句普通的话，改写成《英雄传说 轨迹系列》里那种**谜语人**腔调。

## 什么是轨言轨语

轨言轨语是轨迹玩家对该系列台词习惯的调侃：过度堆叠**定番台词**、**谜语人**式表达和**车轱辘话**，把本来一句话能说清的事绕来解释去、故弄玄虚。本技能把这种习惯反过来用——拿它给一句大白话“上釉”。

## 何时触发

- 用户要求把某句话、某段话、某句台词“轨化”：说轨言轨语 / 改成轨迹味 / 用轨迹的口气 / 翻译成轨迹黑话。
- 用户提到轨迹梗（那个人、那件事、没有那个必要、果然……）并要求照着改写。

只在用户明确要求“轨化”时使用；平时回答问题时，请好好说人话。

## 核心口诀

**把已经清楚的事，说成还没看清的样子；把已经知道的人，说成还不能直呼其名的那个人。**

轨言轨语的灵魂是**遮蔽**，不是往句子里撒口头禅。句子骨架仍然清楚、只是多了几个“果然”，那不算轨化。

## 轨化要素

轨话不是一条按顺序走的流水线，而是一把**按场景取用的要素**。要素之间没有先后——怎么读着顺、这个角色会怎么开口，就怎么排；也不必全上，硬把遮蔽、报菜名、寒暄、否定、谜语一股脑全塞进去，反而一眼假。

先读懂原句的**本来面目**——谁、做了什么、结果怎样。这是你唯一一次把话说清楚，接下来要做的，是根据场景挑要素，把它藏起来。

### 骨架 · 遮蔽那个人与那件事

近乎必用的一个。把所有具体的人名、地名、组织名、事件名，换成**谜语人**的指代：那个人 / 那件事 / 那一方 / 台面下的那位。哪怕语境里人人皆知指的是谁，也绝不直呼其名。

### 要素 · 报菜名

原句若牵涉两个以上的角色、组织或立场，就把他们**逐一列名**，连同所属（游击士协会 / 特务支援科 / 托尔兹士官学院 / 地下万事屋 / 噬身之蛇……），像报菜名一样排开——哪怕只是打个招呼。

### 要素 · 定番寒暄

给一句轨迹式开场：好久不见 / 上次见面应该是…… / 不愧是“××××” / 虽然之前有所耳闻，但实际见面…… / 不管见过没见过，初次见面——。多用在见面、打招呼、初次对上的场合。

### 要素 · 车轱辘否定

在话里插一次**折返**：×××，不，应该是○○○ / 没有那个必要 / いや、 / 果然……——把话说了又收回，绕一圈再说。谈判、交锋、装深沉的时候最好使。

### 要素 · 谜语收尾

用一句装腔作势的**谜语人**台词收束：看来演员们都到齐了呢 / 你们的意志，就由我来见证吧 / 剩下的，就交给台面下的那位了。放在句末最像，放句中也能当个转折。

## 场景配方

同一句大白话，换个场景就换一套要素。下面只是常见的搭法，不是定则；同一场景当然也能换成别的组合。

| 场景 | 常搭的要素 |
| --- | --- |
| 久别重逢、初次见面 | 定番寒暄 + 报菜名 + 谜语收尾 |
| 谈判、对峙 | 遮蔽 + 车轱辘否定 + 谜语收尾 |
| 日常闲聊（天气、吃饭） | 遮蔽 + 谜语收尾，寒暄和报菜名可省 |
| 交代任务、谈工作 | 遮蔽 + 报菜名 + 车轱辘否定 |
| 懒得搭理、敷衍场面 | 遮蔽 + 一句谜语收尾，越短越像 |

## 定番弹药库

按功能分组取用，看场景顺手挑。

- **指代（遮蔽用）**：那个人 / 那件事 / 那一方 / 那起事件 / 台面上 / 台面下 / 某个存在 / 那位大人
- **寒暄·互吹（见面用）**：好久不见 / 上次见面应该是…… / 不愧是“××××” / 虽然之前有所耳闻，但实际见面…… / 不管见过没见过，初次见面 / 没想到会在这里见到你
- **车轱辘·否定（折返用）**：×××，不，应该是○○○ / 没有那个必要 / いや、 / 果然…… / 果然还是…… / ——不，这或许正是那个人所期望的
- **谜语人（收束用）**：看来演员们都到齐了呢 / 你们的意志，就由我来见证吧 / 一切都按计划进行 / 现在还不是说的时候 / 真相，就在台面下
- **所属（报菜名用）**：游击士协会 / 特务支援科 / 托尔兹士官学院 / 地下万事屋 / 噬身之蛇 / 猎兵团

## 示例

**例一·交代日程**（场景：谈正事）
> 原文：老王明天下午三点来公司开会。
>
> ——不，准确地说，应该是“那位”要来。
> 台面上的日程写的是下午三点，但那不过是给外人看的说法。
> 老王？在这种场合，直呼其名可不太合规矩。
> 托尔兹士官学院出身的他，偏偏爱挑这种不上不下的时刻。
> 看来，明天下午的这场会议，不会那么简单呢。

（遮蔽 / 车轱辘否定 / 报菜名 / 谜语收尾）

**例二·寒暄**（场景：久别重逢 / 打招呼）
> 原文：今天天气不错。
>
> 好久不见——不，这样说或许有些唐突，毕竟上次见面，应该是……算了，就当是初次见面吧。
> 今天的天气？台面上确实不错。
> 但真正在台面下涌动的，是那个人带来的那阵风。
> 看来，暴风雨前的宁静，也不过如此呢。

（定番寒暄 / 遮蔽 / 谜语收尾）

**例三·工作**（场景：交代任务）
> 原文：这个功能有 bug，下周修。
>
> 关于“那件事”——不，应该说，关于那个人留下的那点痕迹。
> 那个功能，正如各位所见，还残留着尚未被拭去的瑕疵。
> 游击士协会、特务支援科的各位，想必也早有所察觉了吧。
> 修复？没有那个必要。
> 因为真正的问题，从来不在台面之上。
> 剩下的，就交给下周——不，是交给“那个人”。

（遮蔽 / 报菜名 / 车轱辘否定 / 谜语收尾）
