# 轨言轨语（kiseki-lang）

把任何一句普通的话，改写成《英雄传说 轨迹系列》里那种**谜语人**腔调。

本技能只在用户要求把话“轨化”时出手；其余时候，照常说人话。

## 核心口诀

**把已经清楚的事，说成还没看清的样子；把已经知道的人，说成还不能直呼其名的那个人。**

轨言轨语的灵魂是**遮蔽**，不是往句子里撒口头禅。句子骨架照旧清楚、只多了几个“果然”，那不算轨化。

## 怎么轨化

先读懂原句的**本来面目**——谁、做了什么、结果怎样。这是唯一一次把话说清楚；接下来要做的，是挑几样**要素**，把它藏起来。

要素之间没有先后，也不按流水线走——怎么读着顺、这个角色会怎么开口，就怎么排；更不必全上，硬把遮蔽、报菜名、寒暄、否定、谜语一股脑塞进去，反而一眼假。照原句落在哪个**场景**，再取用相应的要素（见下面的场景配方）。

### 骨架 · 遮蔽

近乎必用。把所有具体的人名、地名、组织名、事件名，换成**谜语人**的指代——哪怕语境里人人皆知指的是谁，也绝不直呼其名。

指代例句：那个人 / 那件事 / 那一方 / 那起事件 / 台面上 / 台面下 / 某个存在 / 那位大人。

### 要素 · 报菜名

原句若牵涉**两方以上**的人物、组织或立场，就让他们排队登场、逐一报上名号；只有一个人、一件事时，轮不到这一条——报菜名留给真正多方的场面。

报的是**原句里本来就有的那几方**：原句提了什么组织，就报什么组织。原句本身就在轨迹的剧情里时，才用轨迹的阵营，且要跟原句对得上——游击士协会 / 特务支援科 / 托尔兹士官学院 / 地下万事屋 / 噬身之蛇 / 猎兵团等等...；原句讲的是普通的事，就报原句自己的组织，别拿这些去替换。

### 要素 · 定番寒暄

给一句轨迹式开场，用在见面、打招呼、初次对上的场合。

例句：好久不见 / 上次见面应该是…… / 不愧是“××××” / 虽然之前有所耳闻，但实际见面…… / 不管见过没见过，初次见面—— / 没想到会在这里见到你。

### 要素 · 车轱辘否定

在话里插一次**折返**，把话说了又收回，绕一圈再说——谈判、交锋、装深沉时最好使。

例句：×××，不，应该是○○○ / 没有那个必要 / いや、 / 果然…… / 果然还是…… / ——不，这或许正是那个人所期望的。

### 要素 · 谜语收尾

用一句装腔作势的**谜语人**台词收束；放句末最像，放句中也能当个转折。

例句：看来演员们都到齐了呢 / 你们的意志，就由我来见证吧 / 一切都按计划进行 / 现在还不是说的时候 / 真相，就在台面下。

## 场景配方

同一句大白话，换个场景就换一套要素。下表只是常见的搭法，不是定则；同一场景当然也能换成别的组合。

| 场景 | 常搭的要素 |
| --- | --- |
| 久别重逢、初次见面 | 定番寒暄 + 报菜名 + 谜语收尾 |
| 谈判、对峙 | 遮蔽 + 车轱辘否定 + 谜语收尾 |
| 日常闲聊（天气、吃饭） | 遮蔽 + 谜语收尾 |
| 交代任务、谈工作 | 遮蔽 + 报菜名 + 车轱辘否定 |
| 懒得搭理、敷衍场面 | 遮蔽 + 一句谜语收尾，越短越像 |

## 示例

下面的每一次改写都只是**一种可能的取法**——挑哪些要素、怎么遣词，每次都得重新来过。

**例一 · 敷衍场面**
> 原文：今天天气不错。
>
> 天气？台面上确实不错。
> 真正在动的，是台面下那阵谁也没提起的风。

取法：遮蔽 + 谜语收尾。日常闲聊，越短越像。

**例二 · 谈正事**（多方才报菜名）
> 原文：让产品部和工程部下周把方案定下来。
>
> 关于“方案”那件事——不，准确说，是关于那两拨人几时肯坐到同一张桌子前。
> 产品部、工程部，台面上写得出名字的，也就这些了。
> 至于真正拍板的，想必早就在台面下谈过一轮了。
> 看来下周的那场会，等的从来不是方案。

取法：遮蔽 + 报菜名（只报原句里真有的那两方）+ 车轱辘否定 + 谜语收尾。

**例三 · 久别重逢**
> 原文：好久没见，你还好吗？
>
> 好久不见——不，这么说或许有些唐突，毕竟上一次面对面，应该是在……算了，就当是初次见面吧。
> 台面上，我们都很好。
> 至于台面下，那个人过得如何，还是不打听为妙。

取法：定番寒暄 + 车轱辘否定 + 遮蔽 + 谜语收尾。

- [ ] 用到的要素跟这个场景对得上吗？
- [ ] 报菜名报的是原句里本来就有的那几方吗？有没有拿轨迹阵营替换掉原句的组织，或硬塞进原句没有的阵营？
- [ ] 要素的顺序读起来像这个角色在开口，而不是在按模板填空吗？
