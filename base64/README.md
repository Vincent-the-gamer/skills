# base64

> [!INFO]
> This skill is practicing the skill scripts, but it's indeed functional <(^v^)>.

This skill can encode/decode text and file into base64 string, or backwards(decode).

Trigger words:

```
# File encode
I'll send you a file next, please call base64 skill to encode this file.

# File decode
<mime-typed base64 string>, please call base64 skill to decode this to a file, and send the file to me.

# String encode
<plain text>, please call base64 skill to encode this string.

# String decode
<base64 string>, please call base64 skill to decode this base64 string, it's original content is plain text.
```
